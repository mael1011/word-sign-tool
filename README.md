# 电子签名工具 (Word Sign Tool)

把手写签名照片自动抠成透明底，直接插入 Word `.docx` 文档，完成电子签名。

纯本地运行，不联网、不上传任何数据。

## 功能特点

- **一键去白底**：上传白纸手写签名照片（JPG / PNG / BMP），自动抠掉白色背景生成透明 PNG
- **可调参数**：去白底强度、墨色（保留原色 / 强制纯黑）、签名打印宽度（厘米）
- **两种插入方式**
  - 浮动定位：签名浮在页面上，用「距页左 / 距页顶」按 0.1cm 微调，可自由摆放
  - 内嵌跟随：签名作为一行内容，可左 / 中 / 右对齐，紧跟「签字：」后面
- **精确插入位置**：可选择「文档末尾」，或「指定文字所在段落之后」（如关键字 `签字`）
- **原文档不改动**：签名只写入新生成的 `原名_已签名.docx`
- **零重依赖**：仅需 Pillow + Python 标准库，直接读写 docx 包（zip + XML），不依赖 python-docx

## 快速开始

### 方式一：直接下载 exe

到 [Releases](https://github.com/mael1011/word-sign-tool/releases) 下载 `SignTool-v1.0.0-win64.exe`（18.5 MB，免安装），双击运行即可（首次启动约 2~5 秒）。

### 方式二：从源码运行

```bash
pip install pillow
python sign_tool.py
```

环境要求：Python 3.8+（需带 tkinter，Windows 官方安装包默认自带）

## 使用步骤

1. 左侧点「选择签名照片」，选一张白纸上的手写签名照片。
   - **去白底强度**：白底没去干净就调大，墨迹变淡就调小
   - **墨色**：保留原色（适合蓝笔）/ 纯黑
   - **签名宽度**：按厘米设置签名实际打印尺寸，一般 3~5cm
2. 右侧点「浏览…」选择要签名的 `.docx`，输出文件自动填为 `原名_已签名.docx`。
3. 选择插入方式：
   - **浮动定位**：坐标以该页左上角为原点；想签在第几页，就把「插入位置」设为该页的关键字段落
   - **内嵌**：签名作为一行内容，适合紧跟「签字：」后面
4. 填「插入位置」：`文档末尾`，或关键字（如 `签字`）表示插入到该段落之后。
5. 点「生成签名并插入 Word」，完成后可直接打开查看。

## 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 提示「仅支持 .docx」 | 先用 Word 把 `.doc` 另存为 `.docx` |
| 签名位置偏了 | 用「距页左 / 距页顶」微调，或改用内嵌方式 |
| 白底去不干净（照片有阴影） | 调高去白底强度，或重拍一张光线均匀的照片 |
| 原文档会被改吗 | 不会。签名只写入新生成的 `_已签名.docx` |

## 实现说明

工具自己读写 `.docx`（本质是 zip 包），主要模块：

- `process_signature()` —— 用 Pillow 按白色阈值生成 alpha 通道，输出透明签名图
- `insert_signature()` —— 解压 docx，写入 `word/media/` 图片、补充关系与 content-types，再按需 生成 `<w:drawing>` 浮动图或内嵌图，最后重新打包
- `run_gui()` —— tkinter 界面
